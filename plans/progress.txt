Ralph Iteration - Feature: sidebar-001 (Collapsible Sidebar)

Date: 2026-02-15

What was implemented:
- Created collapsible sidebar component at front/src/components/layout/sidebar.tsx
- Sidebar features:
  - Collapses/expands with smooth animation
  - Menu items organized in logical groups (Dashboard, Projects, Tasks, Teams, Departments, Processes, Resources, Settings)
  - Submenus expand/collapse properly for Projects and Tasks
  - State persists in localStorage (sidebar-collapsed key)
  - Uses lucide-react icons
  - Responsive design with title hiding when collapsed
- Integrated sidebar into root layout.tsx with flexbox layout

Technical decisions:
- Used React Context (SidebarContext) for managing collapsed state across components
- Created useSidebar() hook for components to access sidebar state
- Used Next.js Link for navigation with usePathname for active state detection
- Created SidebarItem component for handling both simple and submenu items
